# design-taste-frontend

> 仓库来源 · [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) · [上游 SKILL.md](https://github.com/Leonxlnx/taste-skill/blob/main/skills/taste-skill/SKILL.md)

给营销页、作品集和已有网站改版提供前端设计与视觉审查流程。

## 适用场景与核心能力

- 根据简报确定版式、字体和素材方向，改版时先检查已有页面。
- 通过交付前检查核对留白、响应式布局和常见模板化痕迹。

## 下载与安装（给其他项目 / Agent 用）

技能目录为 `skills/taste-skill`。

```bash
npx skills add Leonxlnx/taste-skill --skill design-taste-frontend
```

## 依赖与安全提示

- Node.js 22+ 和 Chrome、Edge 或 Chromium（上游配套脚本）。
- 上游首页记录了配套脚本的依赖。本地安装副本只包含技能说明，安装时可按上游指南获取完整目录。
