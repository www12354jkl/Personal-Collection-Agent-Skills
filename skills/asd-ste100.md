# asd-ste100

> 仓库来源 · [danyuchn/asd-ste100-skill](https://github.com/danyuchn/asd-ste100-skill)

把容易误读的技术英文改写为简化技术英语，适合工具说明、错误消息和代理之间的指令。

## 适用场景与核心能力

- 按文本用途选择严格模式或较宽松的 STE 风格。
- 随附脚本能检查句长和部分结构规则，改写后的含义仍需对照原文。

## 下载与安装（给其他项目 / Agent 用）

技能目录位于仓库根目录。

```bash
npx skills add danyuchn/asd-ste100-skill
```

## 依赖与安全提示

- Python（可选，用于运行 ste-lint.py）。
