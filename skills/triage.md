# triage

> 仓库来源 · [mattpocock/skills](https://github.com/mattpocock/skills) · [上游 SKILL.md](https://github.com/mattpocock/skills/blob/main/skills/engineering/triage/SKILL.md)

按项目角色和状态分流 issue 或外部 Pull Request，补足后续实现所需的背景。

## 适用场景与核心能力

- 核对证据、项目范围和问题归类，整理可执行的任务说明。
- 按追踪器规则推进状态，并记录范围外问题的归类依据。

## 下载与安装（给其他项目 / Agent 用）

技能目录为 `skills/engineering/triage`。

```bash
npx skills@latest add mattpocock/skills --skill triage
```

## 依赖与安全提示

- 项目任务追踪器及标签规则。
