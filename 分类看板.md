# AgentSkills 分类看板

> 基于卡片 Frontmatter 的 `category` 与 `repo` 属性动态生成（依赖已启用的 **Dataview** 插件）。静态 Markdown 总表与 Agent 检索入口见 [INDEX.md](INDEX.md)。
>
> **维护约定**：新增卡片时在顶部属性填写 `category` 即可自动归类，无需移动文件位置；可选标准分类：`规划与需求`、`工程与架构`、`Agent编排`、`前端与设计`、`图表与文档`、`写作与教学`、`图像与视频`、`系统与运维`、`插件与工具`。

---

## 分类总览

```dataview
TABLE WITHOUT ID
  key AS "分类",
  length(rows) AS "数量",
  slice(sort(rows.file.link), 0, 6) AS "卡片预览（前 6 项）"
FROM "skills" OR "plugins"
GROUP BY default(category, "未分类")
SORT length(rows) DESC, key ASC
```

## 按使用场景浏览（Skills）

### 规划与需求

```dataview
TABLE WITHOUT ID
  file.link AS "名称",
  replace(default(repo, "-"), "https://github.com/", "") AS "来源仓库",
  choice(reviewed, "✅", "⬜") AS "已审",
  description AS "用途说明"
FROM "skills"
WHERE category = "规划与需求"
SORT file.name ASC
```

## 按来源仓库筛选（技能套件）

### 多技能套件总览（2 张卡片及以上）

```dataview
TABLE WITHOUT ID
  key AS "来源仓库",
  length(rows) AS "数量",
  slice(sort(rows.file.link), 0, 8) AS "包含卡片（前 8 项）"
FROM "skills" OR "plugins"
GROUP BY replace(default(repo, "未填仓库"), "https://github.com/", "")
WHERE length(rows) >= 2
SORT length(rows) DESC, key ASC
```

### 套件明细：mattpocock/skills

```dataview
TABLE WITHOUT ID
  file.link AS "名称",
  default(category, "未分类") AS "分类",
  description AS "用途说明"
FROM "skills"
WHERE contains(default(repo, ""), "mattpocock/skills")
```


### 独立仓库卡片（单仓单卡）

```dataview
TABLE WITHOUT ID
  rows[0].file.link AS "名称",
  default(rows[0].category, "未分类") AS "分类",
  key AS "来源仓库",
  rows[0].description AS "用途说明"
FROM "skills" OR "plugins"
GROUP BY replace(default(repo, "未填仓库"), "https://github.com/", "")
WHERE length(rows) = 1
SORT default(rows[0].category, "未分类") ASC, rows[0].file.name ASC
```

## 待整理监控

### 尚未填写 `category` 的卡片

```dataview
LIST
FROM "skills" OR "plugins"
WHERE !category
SORT file.name ASC
```

### 尚未审核（`reviewed: false`）的卡片

```dataview
TABLE WITHOUT ID
  file.link AS "名称",
  default(category, "未分类") AS "分类",
  replace(default(repo, "-"), "https://github.com/", "") AS "来源仓库"
FROM "skills" OR "plugins"
WHERE reviewed != true
SORT category ASC, file.name ASC
```
