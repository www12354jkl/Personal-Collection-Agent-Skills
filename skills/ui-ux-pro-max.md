从本地设计资料库检索样式、配色、字体、图表和交互准则，用于界面设计与审查。

## 适用场景与核心能力

- 针对产品和技术栈给出设计系统及组件建议。
- 按指定技术栈查询响应式、可访问性和交互细节。

## 下载与安装（给其他项目 / Agent 用）

技能目录为 `.claude/skills/ui-ux-pro-max`。

```bash
npx ui-ux-pro-max-cli init --ai codex
```

- Python 3（本地搜索）。
- Node.js（使用官方 CLI 安装时）。
- 官方工具可按 Agent 类型安装。技能自带的设计资料查询通过本地 Python 脚本运行。
