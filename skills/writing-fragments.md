# writing-fragments

> 仓库来源 · [mattpocock/skills](https://github.com/mattpocock/skills) · [上游 SKILL.md](https://github.com/mattpocock/skills/blob/main/skills/in-progress/writing-fragments/SKILL.md)

通过问答捕捉可用的写作片段，并持续积累在一份 Markdown 稿件中。

## 适用场景与核心能力

- 收录观察、例子、金句、空白和待考证的想法。
- 在探索阶段先保存素材，后续可交给其他写作技能组织。
- 相关技能包括 [writing-beats](writing-beats.md)、[writing-shape](writing-shape.md)。
