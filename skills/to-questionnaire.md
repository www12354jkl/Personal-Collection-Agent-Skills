# to-questionnaire

> 仓库来源 · [mattpocock/skills](https://github.com/mattpocock/skills) · [上游 SKILL.md](https://github.com/mattpocock/skills/blob/main/skills/productivity/to-questionnaire/SKILL.md)

把缺少的信息写成问卷，交给掌握实际情况的人填写或在会议中共同梳理。

## 适用场景与核心能力

- 先确定受众和回收结果，再围绕需要补齐的信息拟题。
- 将问题按主题组织为 Markdown 文档，可为具体场景提供足够背景。

## 下载与安装（给其他项目 / Agent 用）

技能目录为 `skills/productivity/to-questionnaire`。

```bash
npx skills@latest add mattpocock/skills --skill to-questionnaire
```
