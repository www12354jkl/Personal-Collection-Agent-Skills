# grilling

> 仓库来源 · [mattpocock/skills](https://github.com/mattpocock/skills) · [上游 SKILL.md](https://github.com/mattpocock/skills/blob/main/skills/productivity/grilling/SKILL.md)

把复杂设计整理成决策树，通过分轮提问逐步澄清依赖关系。

## 适用场景与核心能力

- 每轮聚焦前置决策已经确定的问题，并为每题附建议答案。
- 根据用户的回答更新决策树，下一轮再处理新解锁的问题。

## 下载与安装（给其他项目 / Agent 用）

技能目录为 `skills/productivity/grilling`。

```bash
npx skills@latest add mattpocock/skills --skill grilling
```

## 依赖与安全提示

- 支持多轮对话的 Agent。
