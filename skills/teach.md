# teach

> 仓库来源 · [mattpocock/skills](https://github.com/mattpocock/skills) · [上游 SKILL.md](https://github.com/mattpocock/skills/blob/main/skills/productivity/teach/SKILL.md)

把一个主题展开成跨会话的学习过程，保留主题目标、参考资料和学习记录。

## 适用场景与核心能力

- 围绕学习者目标生成课程、速查页与资源清单。
- 以连续的学习记录追踪已经掌握的内容，给下一课提供上下文。

## 下载与安装（给其他项目 / Agent 用）

技能目录为 `skills/productivity/teach`。

```bash
npx skills@latest add mattpocock/skills --skill teach
```

## 依赖与安全提示

- 可写入的学习工作区。
- 浏览器可打开 HTML 课程。
