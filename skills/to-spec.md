# to-spec

> 仓库来源 · [mattpocock/skills](https://github.com/mattpocock/skills) · [上游 SKILL.md](https://github.com/mattpocock/skills/blob/main/skills/engineering/to-spec/SKILL.md)

把已有对话和代码上下文综合成工程规格，适合需求已形成共识的阶段。

## 适用场景与核心能力

- 描述问题、方案、用户情境和测试接缝，沿用项目的领域语言。
- 与用户核对测试接缝后，工作流可将规格写入已配置的任务追踪器。
- 相关技能包括 [setup-matt-pocock-skills](setup-matt-pocock-skills.md)、[to-tickets](to-tickets.md)。

## 下载与安装（给其他项目 / Agent 用）

技能目录为 `skills/engineering/to-spec`。

```bash
npx skills@latest add mattpocock/skills --skill to-spec
```

## 依赖与安全提示

- 项目任务追踪器与分流标签配置。
