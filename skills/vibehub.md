# vibehub

> 仓库来源 · [oil-oil/vibe-hub-skill](https://github.com/oil-oil/vibe-hub-skill) · [上游 SKILL.md](https://github.com/oil-oil/vibe-hub-skill/blob/main/skills/vibehub/SKILL.md) · [VibeHub 网站](https://vibe-hub.org)

在编程协作中识别准确的产品、界面和开发术语，并为术语附上 VibeHub 解释链接。

## 适用场景与核心能力

- 把口语化需求关联到已有的 UI、Git 或软件工程术语。
- 按术语配置批量查找候选，优先引用匹配当前语境的条目。

## 下载与安装（给其他项目 / Agent 用）

技能目录为 `skills/vibehub`。

```bash
npx skills add oil-oil/vibe-hub-skill
```

## 依赖与安全提示

- Node.js（本地术语查找脚本）。
- 访问 VibeHub 术语站时需要网络。
