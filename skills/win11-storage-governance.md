# win11-storage-governance

> 仓库来源 · [Nongfsq/win11-storage-governance-kit](https://github.com/Nongfsq/win11-storage-governance-kit) · [上游 SKILL.md](https://github.com/Nongfsq/win11-storage-governance-kit/blob/main/skills/win11-storage-governance/SKILL.md)

制定 Windows 11 系统盘清理、开发缓存迁移和长效维护方案。

## 适用场景与核心能力

- 按存储占用识别需要进一步核对的缓存和应用数据。
- 记录迁移步骤、验证办法和回退路径，便于人工审核与分批实施。

## 下载与安装（给其他项目 / Agent 用）

技能目录为 `skills/win11-storage-governance`。

在上游仓库中按 README 使用安装脚本，或将指定技能目录完整复制到目标 Agent 的技能目录。

## 依赖与安全提示

- Windows 11。
- 运行系统检查时使用 PowerShell。
- 方案可在本地整理，只需记录容量和迁移所需路径。
