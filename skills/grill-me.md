# grill-me

> 仓库来源 · [mattpocock/skills](https://github.com/mattpocock/skills) · [上游 SKILL.md](https://github.com/mattpocock/skills/blob/main/skills/productivity/grill-me/SKILL.md)

用一轮轮问答检验一个计划或设计，适合没有项目文档也能展开的讨论。

## 适用场景与核心能力

- 调用 grilling，按决策依赖安排提问顺序。
- 每轮覆盖当前能回答的问题，并给出建议答案供确认。
- 相关技能包括 [grilling](grilling.md)。

## 下载与安装（给其他项目 / Agent 用）

技能目录为 `skills/productivity/grill-me`。

```bash
npx skills@latest add mattpocock/skills --skill grill-me
```
