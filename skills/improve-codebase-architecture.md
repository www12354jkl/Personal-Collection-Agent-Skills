# improve-codebase-architecture

> 仓库来源 · [mattpocock/skills](https://github.com/mattpocock/skills) · [上游 SKILL.md](https://github.com/mattpocock/skills/blob/main/skills/engineering/improve-codebase-architecture/SKILL.md)

扫描代码库中的架构摩擦，把深模块重构机会整理成 HTML 报告。

## 适用场景与核心能力

- 结合改动热点、领域词汇和 ADR 选择值得调查的模块。
- 将潜在重构方案可视化，再对选中的方案展开设计问答。
- 相关技能包括 [codebase-design](codebase-design.md)、[domain-modeling](domain-modeling.md)。
