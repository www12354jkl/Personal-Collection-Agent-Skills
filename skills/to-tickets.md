# to-tickets

> 仓库来源 · [mattpocock/skills](https://github.com/mattpocock/skills) · [上游 SKILL.md](https://github.com/mattpocock/skills/blob/main/skills/engineering/to-tickets/SKILL.md)

将计划或规格拆成可端到端验证的任务，明确每项任务的阻塞关系。

## 适用场景与核心能力

- 优先选择能尽早穿透系统的纵向切片。
- 整理任务标题和验收范围，按配置发布并关联依赖。
- 相关技能包括 [to-spec](to-spec.md)、[implement-spec](implement-spec.md)。

## 下载与安装（给其他项目 / Agent 用）

技能目录为 `skills/engineering/to-tickets`。

```bash
npx skills@latest add mattpocock/skills --skill to-tickets
```

## 依赖与安全提示

- 已配置的项目任务追踪器。
