# grill-with-docs

> 仓库来源 · [mattpocock/skills](https://github.com/mattpocock/skills) · [上游 SKILL.md](https://github.com/mattpocock/skills/blob/main/skills/engineering/grill-with-docs/SKILL.md)

通过问答打磨已有项目中的计划，并把形成共识的术语与决策写进文档。

## 适用场景与核心能力

- 结合 grilling 的决策树提问和 domain-modeling 的领域建模流程。
- 将稳定结论沉淀为项目词汇表或 ADR，便于后续开发引用。
- 相关技能包括 [grilling](grilling.md)、[domain-modeling](domain-modeling.md)。
