# prototype

> 仓库来源 · [mattpocock/skills](https://github.com/mattpocock/skills) · [上游 SKILL.md](https://github.com/mattpocock/skills/blob/main/skills/engineering/prototype/SKILL.md)

针对一个尚无答案的设计问题，制作可运行、可丢弃的原型。

## 适用场景与核心能力

- 逻辑原型可用单页 HTML 展示状态变化和引导演示。
- 界面原型把多种方案放在同一路由下，方便操作和比较。

## 下载与安装（给其他项目 / Agent 用）

技能目录为 `skills/engineering/prototype`。

```bash
npx skills@latest add mattpocock/skills --skill prototype
```

## 依赖与安全提示

- 项目现有前端环境，或可打开单页 HTML 的浏览器。
